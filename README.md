# E-Commerce Frontend

A simple e-commerce frontend built with React and Tailwind CSS.

## Features

- Product search
- Category filtering
- Product details page
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Cart total
- Simple login with username
- Responsive design

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Lucide React
- Vite

## Run Locally

```bash
npm install
npm run dev
